// Dual Priority Blocking Queues (Lift.java)
public class Lift {
    // Min-Heap for UP stops (ascending order)
    private final PriorityBlockingQueue<Integer> upStops = 
        new PriorityBlockingQueue<>();

    // Max-Heap for DOWN stops (descending order)
    private final PriorityBlockingQueue<Integer> downStops = 
        new PriorityBlockingQueue<>(11, (a, b) -> Integer.compare(b, a));

    public void addStop(int targetFloor) {
        if (targetFloor > currentFloor) {
            upStops.offer(targetFloor);
        } else if (targetFloor < currentFloor) {
            downStops.offer(targetFloor);
        }
    }
}

SCAN Algorithm & Dual Heap Queues

PriorityBlockingQueue Min-Heap (UP) Max-Heap (DOWN) SCAN Algorithm Dynamic Re-bucketing
  • 1

    Dual Min/Max Heap Queues: `upStops` uses a min-heap for ascending floor requests, while `downStops` uses a max-heap comparator `(a, b) -> Integer.compare(b, a)` for descending floor requests.

  • 2

    SCAN Elevator Scheduling: The elevator continues moving in its active direction, servicing queued stops sequentially before reversing direction to drain the opposing queue.

  • 3

    Dynamic Queue Re-bucketing: Automatically shifts stale or passed floor requests to the opposing queue if an elevator passes a requested floor before servicing it.

// Intrinsic Monitor Boarding Synchronization (LiftController.java)
private void waitForBoarding(Lift lift, int pickupFloor) {
    synchronized (lift.getLock()) {
        while (lift.getStatus() != LiftStatus.OPEN) {
            lift.getLock().wait(); // YIELD thread until elevator arrives & opens doors
        }
        
        // Collect passenger car call destination floors
        List<Integer> destinations = liftView.getDestinationFloors();
        lift.requestTrip(destinations);
        
        // Wake up elevator worker thread to resume movement
        lift.getLock().notifyAll();
    }
}

  • 1

// Nearest Elevator Selection Heuristic (LiftService.java)
public Lift assignLift(int floor, LiftDirection dir) {
    List<Lift> allLifts = repo.getAllLifts();
    Lift bestLift = null;
    int minScore = Integer.MAX_VALUE;

    for (Lift lift : allLifts) {
        int score = calculateCandidateScore(lift, floor, dir);
        if (score < minScore) {
            minScore = score;
            bestLift = lift;
        }
    }
    bestLift.requestPickup(floor);
    return bestLift;
}
